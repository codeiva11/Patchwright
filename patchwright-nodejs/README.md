#### Patchwright is a patched build of the Playwright Testing and Automation Framework. </br> It can be used as a drop-in replacement for Playwright. It reduces common driver-level automation signals; it cannot guarantee that every anti-bot system will accept it.

## Usage
#### Just change the import and use it like playwright. Patchwright is a drop-in-replacement for Playwright!

> [!IMPORTANT]  
> Patchwright only patches CHROMIUM based browsers. Firefox and Webkit are not supported.

```js
// patchwright here!
const { chromium } = require('patchwright');

(async () => {
  const browser = await chromium.launch();
  const page = await browser.newPage();
  await page.goto('http://example.com');
  // other actions...
  await browser.close();
})();
```

### Best Practice  - use Chrome without Fingerprint Injection

To reduce the most common automation signals, use the following configuration:
```js
chromium.launchPersistentContext("...", {
    channel: "chrome",
    headless: false,
    viewport: null,
    // do NOT add custom browser headers or userAgent
});
```

> [!NOTE]
> We recommend using Google Chrome instead of Chromium.
> You can install it via `npx patchwright install chrome` (or via any other installation method) and use it with `channel: "chrome"`.

## Patches

### [Runtime.enable](https://vanilla.aslushnikov.com/?Runtime.enable) Leak
Patchwright does not enable [Runtime.enable](https://vanilla.aslushnikov.com/?Runtime.enable) during startup. It enables the domain lazily only when the page asks for console or page-error events, because Chrome cannot deliver those without it.

### [Console.enable](https://vanilla.aslushnikov.com/?Console.enable) Leak
Patchwright does not enable the CDP `Log`/`Console` domains at startup. Console messages are collected on demand when a listener is attached.

### Command Flags Leaks
Patchwright tweaks the Playwright Default Args to avoid detection by Command Flag Leaks. This (most importantly) affects:
- `--disable-blink-features=AutomationControlled` (added) to avoid navigator.webdriver detection.
- `--enable-automation` (removed) to avoid navigator.webdriver detection.
- `--disable-popup-blocking` (removed) to avoid popup crashing.
- `--disable-component-update` (removed) to avoid detection as a Stealth Driver.
- `--disable-default-apps` (removed) to enable default apps.
- `--disable-extensions` (removed) to enable extensions

### General Leaks
Patchwright patches some general leaks in the Playwright codebase. This mainly includes poor setups and obvious detection points.

### Closed Shadow Roots
Patchwright is able to interact with elements in Closed Shadow Roots. Just use normal locators and Patchwright will do the rest.
<br/>
Patchwright is now also able to use XPaths in Closed Shadow Roots.

## Stealth

Patchwright is not claimed to be universally undetectable. Detectors combine browser signals,
network reputation, IP/ASN, account history, request timing and server-side models; no client
library can guarantee a pass against all of them.

The repository's own checks are the source of truth:
- `utils/detection_smoke_test.mjs`
- `utils/custom_tests/runtime_smoke_test.mjs`
- `utils/custom_tests/service_worker_smoke_test.mjs`
- `utils/custom_tests/tls_ja4_check.mjs`

Third-party detector pages can change without notice, so historical pass screenshots are not a
continuing guarantee.

## Extended Patchwright API
#### **`evaluate`** Method <sub>([`Frame.evaluate`](https://playwright.dev/docs/api/class-frame#frame-evaluate), [`Page.evaluate`](https://playwright.dev/docs/api/class-page#page-evaluate),  [`Locator.evaluate`](https://playwright.dev/docs/api/class-locator#locator-evaluate),  [`Worker.evaluate`](https://playwright.dev/docs/api/class-worker#worker-evaluate),  [`JSHandle.evaluate`](https://playwright.dev/docs/api/class-jshandle#js-handle-evaluate))</sub>
- Added `isolatedContext`  to choose Execution Context (Main/Isolated). `Bool` (*optional*, Defaults to `true`)
```diff
object.evaluate(
    pageFunction: Function | string,
    arg?: Arg,
    ...,
+   isolatedContext: boolean = true
)
```

#### **`evaluateHandle`** Method <sub>([`Frame.evaluateHandle`](https://playwright.dev/docs/api/class-frame#frame-evaluate-handle), [`Page.evaluateHandle`](https://playwright.dev/docs/api/class-page#page-evaluate-handle), [`Locator.evaluateHandle`](https://playwright.dev/docs/api/class-locator#locator-evaluate-handle), [`Worker.evaluateHandle`](https://playwright.dev/docs/api/class-worker#worker-evaluate-handle), [`JSHandle.evaluateHandle`](https://playwright.dev/docs/api/class-jshandle#js-handle-evaluate-handle))</sub>
- Added `isolatedContext`  to choose Execution Context (Main/Isolated). `Bool` (*optional*, Defaults to `true`)
```diff
object.evaluateHandle(
    pageFunction: Function | string,
    arg?: Arg,
    ...,
+   isolatedContext: boolean = true
)
```

#### **`evaluateAll`** Method <sub>([`Locator.evaluateAll`](https://playwright.dev/docs/api/class-locator#locator-evaluate-all))</sub>
- Added `isolated_context`  to choose Execution Context (Main/Isolated). `Bool` (*optional*, Defaults to `True`)
```diff
Locator.evaluateAll(
    pageFunction: Function | string,
    arg?: Arg,
    ...,
+   isolatedContext: boolean = true
)
```
